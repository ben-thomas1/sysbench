# Possible additions

These are ideas for future work, not implemented features.

- Memory: memcpy bandwidth, explicit TLB-pressure tests, configurable working sets.
- CPU: FP16, hardware crypto, integer division, SIMD shuffle throughput.
- Storage: block-size sweeps, mixed reads/writes, concurrent writes, metadata operations.
- System: signals, mmap/munmap, fork/exec.
- Network: UDP and Unix-domain sockets.
- GPU: FP64 where supported, quantized arithmetic, concurrent compute and transfers.
- Matrix: DGEMM, GEMV, and batches of small matrices.
- Reproducibility: machine-readable output, explicit CPU placement, configurable
  durations, and repeated-run summaries.
